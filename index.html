01 · Video generation

AI Educational Video Engine

Transforms lesson content into animated explainer videos for NCERT Grades 6–12.

  • The AI writes a typed storyboard, never code or pixels. Deterministic TypeScript draws every frame.
  • 15 scene types (geometry, physics, chemistry, biology, graphs, Venn diagrams, quizzes) and an 18-element doodle system.
  • Browser-free rendering at about 17 ms per frame with resvg-js, plus MathJax equations and about 150 automated tests.

02 · Interactive learning

SimLab: Simulation Engine

Educators describe a learning goal; SimLab builds an interactive simulation for Maths, Physics, Chemistry or Biology.

  • Schema-driven definitions validated with Zod. The AI selects registered patterns and can't inject executable code.
  • A deterministic model and clock (play, pause, step, seek), separate from rendering.
  • Simulations include projectile motion, sound waves, refraction of light, circuits and electrostatics, with 20+ Vitest test files.

03 · Classroom video

Class2Clips

Turns a long classroom recording into clean, concept-focused teaching videos.

  • Offline transcription with whisper.cpp. The AI finds the real teaching segments and groups them by concept.
  • Every AI timestamp is bounded against the real video length. One model once returned 277 hours for a 96-minute class.
  • Teachers approve the segments, and FFmpeg renders the final video in a background job queue.

04 · Exam QA automation

Question Paper QA Tool

Checks each exam paper against its online version, question by question and option by option.

  • Character-level text diff, perceptual-hash figure matching, blur detection, duplicate and answer-key checks.
  • A local vision-AI second opinion, benchmarked on 34 real cases: 84.8% accuracy, advisory only.
  • Validated on 7 real papers and rolled out to the QA team. It runs offline on any laptop.

How I build

Engineering principles

Let the AI make decisions; let deterministic code produce the output.

01

Structured inputs

Defined specifications instead of unrestricted generated code wherever practical.

02

Deterministic execution

Calculations and critical behaviour stay in explicit, testable logic.

03

Validation first

Invalid inputs and out-of-bounds model output are caught before rendering or execution.

04

Reusable architecture

Shared components instead of isolated demos.

05

Test real outputs

Check the actual frames, PDFs and numbers, not just that the code runs.

06

Benchmark the AI

Measure accuracy on real cases before a model reaches users.
